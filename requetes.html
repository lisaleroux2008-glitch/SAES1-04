Requête 2: Dans une réflexion en lien avec l’origine de ses produits : On veut comme indicateur le CA total généré à ce jour avec les fournisseurs de l’UE ?

SELECT SUM(DetailCommande.Quantité * Produit.CoutAchat) AS CA_Total
FROM ((Fournisseur INNER JOIN Pays ON Fournisseur.NoPays = Pays.NoPays)
INNER JOIN Produit ON Fournisseur.NoFour = Produit.NoFour)
INNER JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf Produit]
WHERE Pays.UE = 'Membre';


Requête 3: Dans une réflexion en lien avec la santé : On veut comme indicateur le chiffre d’affaire généré (montant total des ventes) annuel pour les catégories desserts ou boissons.
SELECT YEAR(DateCde) AS Annee, Categorie.NomCateg, SUM(DetailCommande.Quantité * Produit.CoutAchat) AS CA
FROM ((Categorie INNER JOIN Produit ON Categorie.CodeCateg = Produit.CodeCateg)
INNER JOIN DetailCommande ON DetailCommande.[Réf Produit] = Produit.RefProd)
INNER JOIN Commande ON Commande.[N° commande] = DetailCommande.[N° commande]
WHERE Categorie.NomCateg = 'Boissons' OR Categorie.NomCateg = 'Desserts'
GROUP BY YEAR(DateCde), Categorie.NomCateg;


Requête 4: Dans une réflexion en lien avec l’offre commerciale : Calcul de l’indicateur nombre de produits carnés non commandés actuellement ?
SELECT COUNT(*) AS NbProduitsCarnesNonCommandes
FROM (Categorie INNER JOIN Produit ON Categorie.CodeCateg = Produit.CodeCateg)
LEFT JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf Produit]
WHERE Categorie.NomCateg = 'Produits carnés'AND DetailCommande.[Réf Produit] IS NULL


Requête 5: Dans une réflexion sur le partenariat client : A-t-on des clients pilotes d’un réseau partenaire ayant autant de commandes que les clients partenaires ?
SELECT C.CodeCliPart, COUNT(C.CodeCli) AS Nb_Clients, COUNT(Com.[N° commande]) AS Nb_Total_Commandes
FROM Clientele AS C LEFT JOIN Commande AS Com ON C.CodeCli = Com.CodeCli
GROUP BY C.CodeCliPart;
